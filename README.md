# Mine_Horror

**Mine_Horror** is a single-player horror game developed in Unity. The player takes on the role of a man searching for his wife in an abandoned mine/laboratory, facing terrifying creatures, solving puzzles, and navigating a suspenseful environment.

## 🎮 Game Description

In Mine_Horror, you explore a dark and abandoned mine/laboratory filled with mysteries and dangers. The player must survive by solving puzzles, avoiding or confronting enemies, and uncovering the secrets of the location to find his missing wife. The game combines elements of horror, shooter mechanics, and puzzle-solving.

## 🛠️ Technologies

- **Unity** — game engine used for development.  
- **C#** — primary programming language.  
- **Android / PC** — target platforms.
